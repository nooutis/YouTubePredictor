## Data preparation

Pipeline that turns the raw YouTube dataset into a clean table, a fixed train/val/test split and feature files. Everything is generated by `src/data.py` and `src/image_features.py`.

### Files (`data/`)
| File | Content |
|---|---|
| `split.csv` | `video_id`, `channel_title`, `category`, `y`, `y_top`, `fold`, `split` |
| `features.csv` | `log_subscribers`, `log_duration`, category one-hot, simple title features |
| `image_features.csv` | face, emotion, OCR text and colour/contrast features per thumbnail |
| `report.txt` | rows dropped at each step and split sanity checks |

`video_id` is the key everywhere. Thumbnails are named `<video_id>.jpg`. Always join other data (embeddings, predictions) on `video_id`, and use the `split` column as is (do not re-split).

### Cleaning (26,524 -> 24,477 videos, 11,505 channels)
- Cumulative views are fixed with a running max; videos whose views drop by more than 20% from the running maximum are removed (73).
- Videos with `day19 == 0` are removed (12), since the log ratio is undefined.
- Videos without a valid 320x180 thumbnail are removed (1,962 after the other filters).

### Target
- `y = log(day19 / subscribers)`: log of views after 20 days relative to channel size. This removes most of the "big channel = many views" effect (correlation with log(subscribers) drops from 0.53 for raw log views to -0.20).
- `y_top`: 1 if `y` is in the top quartile. The threshold is computed on the train split only.
- Do not use `day0`-`day19` as model inputs, they are the outcome.

### Split
`StratifiedGroupKFold` with 10 folds (seed 42), stratified by category and grouped by channel, so no channel appears in more than one split. Fold 0 = test (10%), fold 1 = val (10%), folds 2-9 = train (80%).

### Features
- **Metadata and title** (`features.csv`): `log_subscribers`, `log_duration`, category one-hot, title length, word count, uppercase ratio, digits, `?`, `!`, emoji, brackets, truncated flag.
- **Image** (`image_features.csv`): number, size and position of faces, emotion probabilities of the largest face (DeepFace), OCR text features (EasyOCR: presence, area, height, uppercase ratio, overlap with the title), brightness, contrast, saturation, colourfulness and edge density (OpenCV).

### How to reproduce
```
python src/data.py --csv youtube_dataset_local_images.csv --valid valid_images.csv --out data/
```
`valid_images.csv` lists videos whose thumbnail exists and opens correctly. `image_features.py` was run on Kaggle (GPU) with the thumbnails dataset; see the header of the script for the command.

### Findings and limitations
- **Missing thumbnails are not random.** 1,973 videos had no thumbnail in the Kaggle dataset. They are more frequent in Entertainment, People & Blogs, Film & Animation and Music than in News & Politics or Autos, and have a lower median `y` (-5.36 vs -4.82). Results therefore apply to videos whose thumbnails are still available.
- **Image features are weakly associated with `y`** (|r| <= 0.12). Videos with text or faces have higher `y` on average and this holds in most categories, but within the same channel the difference for text is about 0.04 (95% CI includes 0) and for faces about 0.07 (CI barely excludes 0; intervals are approximate and probably somewhat optimistic), so most of the raw difference reflects which channels use text and faces. Text and faces mostly reflect which channels use them (production quality, genre), so we describe them as associated with success, not as causing it.
- **Emotion features are exploratory.** Only surprise stands out (mean `y` -3.97 vs about -4.8 for other emotions, 370 videos), and within channels this shrinks to about 0.08. The emotion model is noisy on small 320x180 thumbnails and probably labels many neutral faces as sad or angry.
- OCR was run with the English model, so text in other scripts is detected poorly.
